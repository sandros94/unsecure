# secureGenerate()

> Passwords, tokens and PINs drawn from a buffered CSPRNG, with at least one character from every category you enable.

```ts
import { secureGenerate } from "unsecure/generate";

secureGenerate(); // "Cbl+7L|l[YH#{EsR"
secureGenerate({ length: 32, specials: false }); // "eO1k3t091l72uZTqhY050kEJ6vdB0j0V"
```

## Signature

```ts
function secureGenerate(options?: {
  length?: number;
  uppercase?: boolean | string;
  lowercase?: boolean | string;
  numbers?: boolean | string;
  specials?: boolean | string;
  timestamp?: true | Date;
}): string;
```

## Options

| Option      | Type                | Default | What it does                                                        |
| ----------- | ------------------- | ------- | ------------------------------------------------------------------- |
| `length`    | `number`            | `16`    | Output length in code points. An integer of at least 1.             |
| `uppercase` | `boolean \| string` | `true`  | `false` disables the category. A string replaces its character set. |
| `lowercase` | `boolean \| string` | `true`  | Same.                                                               |
| `numbers`   | `boolean \| string` | `true`  | Same.                                                               |
| `specials`  | `boolean \| string` | `true`  | Same.                                                               |
| `timestamp` | `true \| Date`      | `false` | Prefixes the output with an encoded timestamp, making it sortable.  |

The default sets:

| Category    | Characters                   |
| ----------- | ---------------------------- |
| `uppercase` | `ABCDEFGHIJKLMNOPQRSTUVWXYZ` |
| `lowercase` | `abcdefghijklmnopqrstuvwxyz` |
| `numbers`   | `0123456789`                 |
| `specials`  | `` !@#$%^&*()_+{}:<>?        | [];,./~-= `` |

## What it guarantees

Every enabled category contributes at least one character. The function draws one from each, fills the rest from the combined set, then shuffles the result securely. Drawing uses rejection sampling, so no character is more likely than another.

```ts
// A 32-character alphanumeric token
secureGenerate({ length: 32, specials: false });
// "eO1k3t091l72uZTqhY050kEJ6vdB0j0V"

// A six-digit PIN
secureGenerate({ length: 6, uppercase: false, lowercase: false, specials: false });
// "608811"

// Odd digits only
secureGenerate({
  length: 6,
  uppercase: false,
  lowercase: false,
  specials: false,
  numbers: "13579",
});

// A sortable, timestamped token
secureGenerate({ length: 24, timestamp: true }); // "mtpsscichR^y)%?5u[g%&SS-"
secureGenerate({ length: 24, timestamp: new Date("2023-01-01") });
```

Character sets are iterated by code point, so `length` counts characters the way a reader does and a set holding astral characters never yields half a surrogate pair.

## Errors

| Cause                                               | `code`         |
| --------------------------------------------------- | -------------- |
| `length` is not an integer of at least 1            | `OUT_OF_RANGE` |
| No category is enabled                              | `OUT_OF_RANGE` |
| A character appears in two selected sets            | `OUT_OF_RANGE` |
| The timestamp prefix leaves no room inside `length` | `OUT_OF_RANGE` |
| `timestamp` is an invalid `Date`                    | `OUT_OF_RANGE` |
| `timestamp` is neither `true` nor a `Date`          | `INVALID_TYPE` |

`NaN`, `Infinity` and `5.5` are all out of range for `length`, rather than silently producing something.

## Pitfall: overlapping custom sets

```ts
// "0" is in two sets, so it would be drawn twice as often
secureGenerate({ numbers: "0123456789", specials: "0!" });
// UnsecureError OUT_OF_RANGE
```

The refusal is deliberate. A repeated character skews the very distribution the generator exists to provide. The four default sets are disjoint.

## Pitfall: a length shorter than the number of categories

The one-per-category guarantee needs room. With four categories enabled and `length: 2`, only two of the four guarantees fit; the output is truncated after the shuffle.

```ts
secureGenerate({ length: 2 }); // two of four categories, arbitrarily
secureGenerate({ length: 8 }); // four categories, all guaranteed
```

Keep `length` at least as large as the number of enabled categories.

## Pitfall: the timestamp eats the length

The prefix is counted inside `length`, not added to it.

```ts
secureGenerate({ length: 8, timestamp: true }); // throws: no room left
secureGenerate({ length: 24, timestamp: true }); // prefix plus random tail
```

## Recipe: a token you store as a digest

```ts
import { secureGenerate } from "unsecure/generate";
import { hash } from "unsecure/hash";

const token = secureGenerate({ length: 48, specials: false });
await db.tokens.insert({ userId, tokenHash: await hash(token) });
return token; // shown once, never stored in the clear
```

Dropping specials keeps the token safe to paste into a URL, a header or a shell.

## Recipe: a generated password that clears a quality gate

```ts
import { secureGenerate } from "unsecure/generate";
import { entropy } from "unsecure/entropy";

function generateStrongPassword(minBits = 80) {
  let password: string;
  let result: ReturnType<typeof entropy>;
  do {
    password = secureGenerate({ length: 20 });
    result = entropy(password);
  } while (result.bits < minBits);
  return { password, entropyBits: result.bits };
}
```

A 20-character password over the four default sets clears 80 bits on nearly every draw. The loop is a belt-and-braces check, not a real filter.
