# Give rewards at the promised rate

> Give players loot, crits and rewards at the rate you promised, without the long droughts and lucky streaks that independent rolls produce.

Rolling 1 in 100 for every chest is fair on average and cruel to the person holding the controller: about one player in three opens 100 chests and gets nothing. This module uses the same secure randomness as the rest of the library, but it remembers what came before, so a dry spell always ends. Use it for game drops, rotations and rewards, anywhere feeling fair matters more than staying secret.

## Before you start

- Every deck and chance is an object you own: one per player, per feature, per anything that needs its own luck. Nothing is shared between them.
- Each one exposes `state`, a plain object. Keep it on your server, next to the player's inventory. Whoever can edit it chooses the next result: a pity counter set to 89 of 90 makes the next roll a certain hit.
- Two requests that load the same state at once roll from the same streak, and one of the two saves is lost. Open one player's chests one at a time, or write the state back with a conditional update.
- The draws can't be seeded. To replay a match, record the results.

## Open a chest with guaranteed rare drops

This handler opens one chest for one player: it loads the player's luck from your store, draws, and saves the luck back.

<!-- automd:region src="../../../examples/generate/loot-chest.ts" -->

```ts [loot-chest.ts]
/** Each player's luck, kept on the server next to their inventory. */
interface PlayerLuck {
  legendary?: PityState;
  rare?: PRDState;
}

interface LuckStore {
  load(playerId: string): Promise<PlayerLuck>;
  save(playerId: string, luck: PlayerLuck): Promise<void>;
}

export async function openChest(
  store: LuckStore,
  playerId: string,
): Promise<"legendary" | "rare" | "common"> {
  const luck = await store.load(playerId);
  // 0.6% a chest, climbing after 74 misses, certain on the 90th.
  const legendary = createChance("pity", 0.006, { hard: 90, soft: 74, state: luck.legendary });
  // 5% a chest, with long droughts and lucky streaks smoothed out.
  const rare = createChance("prd", 0.05, { state: luck.rare });
  const loot = createCascade(["legendary", legendary], ["rare", rare], "common").draw();
  await store.save(playerId, { legendary: legendary.state, rare: rare.state });
  return loot;
}
```

<!-- /automd -->

- **Pity for the jackpot**: `"pity"` sits at the nominal 0.6% for 74 chests, then climbs until the 90th is a certain hit. That climb adds hits, so it pays out 1.59% in the end, and `legendary.probability` reports that number.
- **PRD for the common rare**: `"prd"`, short for pseudo-random distribution, starts each streak at 0.38% and adds that much after every miss. A hit sends it back to the start. Over time it still pays 5%, and dry spells stay short: 60 empty chests in a row come up about once in 1,900 streaks, against once in 22 with plain 5% rolls.
- **Order decides who pays**: the cascade asks legendary first and asks rare only when legendary missed, so rare wins 4.92% of chests, not 5%. The cascade's `rates` field shows you that real split.

## Deal cards from a deck

A deck works like a real one: it deals every card once per cycle in a random order, then shuffles. Pass a `Map` of card to count, and `size` with `fill` to pad it out:

```ts
const rewards = createDeck(
  new Map([
    ["gem", 1],
    ["coins", 3],
  ]),
  { size: 10, fill: "nothing" },
);
rewards.draw(); // one gem, three coins and six nothings every 10 draws
const crit = createChance("deck", "1/4"); // a hit exactly once in every 4 rolls
```

The catch is that anyone counting cards knows the end of a deck: after three misses from four, the fourth is certain. `reshuffleAt: 1` starts a new cycle with one card left, so that sure thing never arrives.

## When it fails

Every failure below is a setup mistake, so it throws when you create the object, not later in the middle of a `draw()` or `roll()`:

| Situation                                                                                    | What happens                                                                               |
| -------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| A model other than `"deck"`, `"prd"` or `"pity"`                                             | Throws `UNSUPPORTED`.                                                                      |
| A deck chance given a number, such as `0.25`                                                 | Throws `INVALID_TYPE`. A deck takes a `"hits/cards"` string, since the string is the deck. |
| A string that doesn't read `"hits/cards"`                                                    | Throws `MALFORMED`.                                                                        |
| A probability of `0`, `1` or beyond, or a fraction such as `"0/4"` or `"4/4"`                | Throws `OUT_OF_RANGE`. The range excludes both ends.                                       |
| A deck with no cards, a count below 1, `size` without `fill`, or `size` below the card count | Throws `OUT_OF_RANGE`.                                                                     |
| A saved `state` that doesn't fit, such as a deck order of the wrong length                   | Throws `OUT_OF_RANGE`. Validation checks the shape, not who wrote it.                      |
| A cascade without tiers, or with an outcome named twice                                      | Throws `OUT_OF_RANGE`. A tier that isn't `[name, chance]` is `INVALID_TYPE`.               |

## Options

These go in the last argument of `createChance` or `createDeck`:

| Option               | Default        | Notes                                                                                           |
| -------------------- | -------------- | ----------------------------------------------------------------------------------------------- |
| `hard` (pity)        | required       | The roll that always hits.                                                                      |
| `soft` (pity)        | `hard`         | Rolls at the flat rate before the climb. Leave it out for flat odds with a guarantee at `hard`. |
| `reshuffleAt` (deck) | `0`            | Cards left when the next cycle starts, from `0` to `size - 1`.                                  |
| `state`              | none           | A snapshot from `.state`, to resume after a restart.                                            |
| `generator`          | the shared one | A generator from `createSecureRandomGenerator()`.                                               |

## Going further

Worth knowing once you design your own tables:

- **Who pays for a new outcome**: the odds of one roll always add up to 100%, so a new outcome takes its share from somewhere. In a deck of equal cards, every outcome shrinks. With counts and a `fill`, only the fill shrinks. In a cascade, only the tiers below the new one shrink.
- **Custom models**: a cascade tier is any object with `roll()` and a `probability` number, so a model you write yourself slots in next to the built-in ones.
- **A wheel, not a deck**: regulated gambling and statistical simulation need every draw to be independent of the last. Pick an index against cumulative weights with [`secureRandomNumber`](/generate/random) and keep no state.
