# Generate

> Make tokens, random numbers, identifiers and fair odds from the runtime's cryptographic randomness, and check secrets without leaking timing.

::card-group ::card{title="Secrets" icon="i-lucide-dice-5" to="/generate/secrets"} Generate tokens and passwords, compare them in constant time, turn away weak ones. :: ::card{title="Draw random numbers" icon="i-lucide-shuffle" to="/generate/random"} Integers, bytes, shuffles and delays, with every value in range equally likely. :: ::card{title="Create identifiers" icon="i-lucide-tag" to="/generate/uuid"} UUIDv7 keys that sort by creation time, and UUIDv4 when the time is private. :: ::card{title="Give rewards at the promised rate" icon="i-lucide-layers" to="/generate/odds"} Decks, pity and pseudo-random chances that end droughts without changing the odds. :: ::
