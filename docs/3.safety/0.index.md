# Safety

> Read input from outside without letting it steer your code: parse JSON, decode encoded text, and handle the errors both can throw.

::card-group
::card{title="Parse untrusted JSON" icon="i-lucide-braces" to="/safety/sanitize"}
Parse a request body, or clean one already parsed, without the keys that cause prototype pollution.
::
::card{title="Encode and decode" icon="i-lucide-binary" to="/safety/codecs"}
Turn bytes into hex, base64 or base32 text and back, accepting only the canonical spelling.
::
::card{title="Handle errors" icon="i-lucide-circle-alert" to="/safety/errors"}
Catch `UnsecureError`, tell a client's mistake from your own by its code, and answer each one.
::
::
