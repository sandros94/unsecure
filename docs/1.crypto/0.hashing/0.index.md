# Hashing and MAC

> Fingerprint data with a hash, or sign it with a secret so only the holders of that secret can make or check the signature.

A hash is a fingerprint: it tells you whether data changed. A message authentication code (MAC) is a stamp you can only make with a shared secret, so it also tells you who made it. Neither one is for passwords. [Concepts](/getting-started/concepts#four-things-that-look-like-hashing) explains why, and [Store passwords](/crypto/password-hashing) covers that job.
