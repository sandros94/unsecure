# Crypto

> Fingerprint data, sign messages, derive keys, store passwords and add a second factor, all on the Web Crypto API.

Each page here does one job and comes with code you can copy into your app. If you're not sure which job is yours, the table in [Concepts](/getting-started/concepts#four-things-that-look-like-hashing) sorts them by what you're trying to do.

::card-group ::card{title="Hash data" icon="i-lucide-hash" to="/crypto/hashing/hash"} Fingerprint content with SHA-256 to tell whether it changed. :: ::card{title="Sign and verify messages" icon="i-lucide-signature" to="/crypto/hashing/hmac"} Prove a message came from someone holding a shared secret. :: ::card{title="Derive keys" icon="i-lucide-key-round" to="/crypto/key-derivation"} Turn one root secret into a separate key per purpose. :: ::card{title="Store passwords" icon="i-lucide-lock-keyhole" to="/crypto/password-hashing"} Hash passwords with Argon2 and check them at login. :: ::card{title="Add a second factor" icon="i-lucide-smartphone" to="/crypto/otp"} Enroll an authenticator app and accept each six-digit code once. :: ::
